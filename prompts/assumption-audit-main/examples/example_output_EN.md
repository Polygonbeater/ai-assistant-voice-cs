# Example output (EN) – fictional scenario

**Input (fictional)**: “We must introduce a mandatory registry, otherwise it won’t work.”

1) CLASSIFY: A (politics/public sector). Modules: CSH + ISO 31000.  
2) RED FLAG: Hidden assumption: “mandatory registry” is presented as fact even though it’s a choice.  
   STATUS: Hypothesis, medium confidence, Evidence Tier C, missing alternatives analysis; stop rule: publish 2 alternatives + impact comparison.

3) CORES+  
- Authority: ministry X; accountable: government/parliament  
- Profit: system vendor + institution gaining new power  
- Metric: “fraud reduction” / “control speed”  
- Default: mandatory for all; opt-out impossible  
- Costs: citizens (time, data risk); state (operations)  
- Excluded alternative: targeted checks / voluntary regime

4) TRADE-OFFS  
- Control over privacy; cost borne by citizens.  
- Speed over legitimacy; cost borne by vulnerable groups.  
- Centralization over resilience; cost borne by the state when it fails.

5) ALTERNATIVES  
- Option 1: risk-based targeted checks (lower intrusion, higher investigative capacity needed).  
- Option 2: voluntary registry with benefits (lower coverage, higher legitimacy).

6) TIME (sunset)  
- Expires in 18 months unless fraud drops 30% without error-rate increase.

7) PRE-MORTEM  
- Tick-box: registry exists but fraud shifts elsewhere.  
- Bypass: fake identities / proxy services.  
- Malicious compliance: registry demanded everywhere, blocking services.

8) INTERVENTIONS  
- Opt-out or exemptions for low risk.  
- Mandatory metric justification + published alternatives.  
- Independent audit + remedy path.

9) 2 SENTENCES  
- “This isn’t necessity; it’s a choice—and alternatives aren’t compared.”  
- “Efficient by which metric—and at whose expense?”
