# Versioning

This repository uses **Semantic Versioning** (vMAJOR.MINOR.PATCH).

- Start at **v1.0.0** (first public release of this repo).
- Increment:
  - **PATCH** for wording, clarity, small constraints (no structural changes).
  - **MINOR** for new sections/steps or new required output fields.
  - **MAJOR** for breaking changes (renaming outputs, removing steps, restructuring formats).

Note: The prompt style is inspired by a “V3.1-style” structure, but **this repo is independent** of any strategy prompt releases.
